# Безопасность: куда уходят ваши данные — и как проверить это самому

Этот документ — для тех, кто не готов верить на слово. В нём три части:

1. **Что программа делает с данными** — полный список, без «и т. д.».
2. **Что встроено в программу**, чтобы это нельзя было нарушить незаметно.
3. **Как проверить снаружи**, не доверяя ни программе, ни автору, — от пяти минут без навыков до полного аудита.

И честный раздел о том, чего программа гарантировать не может.

---

## 1. Что программа делает с данными

| Что | Откуда | Куда | Сеть |
|---|---|---|---|
| Архив данных ВК (ZIP) | Ваш диск — вы скачали его у ВК сами | Читается в память, на диск не распаковывается и не меняется | Нет |
| Тексты переписок, стена, друзья, музыка, видео (ссылками) | Архив | База `vk_backup.db` и HTML-страницы в выбранной вами папке | Нет |
| Фото, голосовые, документы, обложки видео | Прямые ссылки внутри архива | Папка архива | **Да — единственное сетевое действие:** GET-запрос файла с файлового сервера ВК |
| Поиск по перепискам, «Мой ВКонтакте в цифрах», «В этот день» | База `vk_backup.db` | Считается на вашем компьютере: в страницу-пульт и в `stats/index.html` архива | Нет |
| Настройки (путь к архиву, папка, разделы) | Вы | `settings.json` рядом с программой | Нет |
| Журналы | Программа | `logs/webui.log` (действия, ошибки), `logs/network.log` (все соединения) | Нет |

Чего в программе **нет**:

- **Пароля и ключа доступа к ВК.** Программа не умеет входить в аккаунт и не обращается к API ВК — такого кода в ней нет. Сайт `vk.com` / `vk.ru` не входит даже в список разрешённых адресов.
- **Серверов автора.** Их нет. Программа не отправляет ни отчётов, ни статистики, ни «анонимной аналитики».
- **Проверки обновлений** и любых других «фоновых» запросов.
- **Сторонних библиотек для сети.** Скачивание файлов — стандартная библиотека Python (`http.client`, `ssl`).

Что уходит на файловый сервер ВК при скачивании одного файла: адрес файла из вашего архива и два заголовка — `User-Agent: VKBackup/0.1` и `Accept-Encoding: identity`. Ни cookies, ни данных аккаунта, ни содержимого архива. Это то же самое, что делает браузер, когда вы открываете фото по ссылке.

## 2. Что встроено в программу

### Сетевой замок — `vkbackup/firewall.py`

Python умеет сообщать о каждом сетевом действии программы — поиске адреса по имени (DNS), соединении, отправке пакета — через аудит-хуки ([PEP 578](https://peps.python.org/pep-0578/)). Замок ставится **первой строкой** программы, до загрузки остального кода (`webui.py`), и снять его нельзя — так устроен Python.

Замок пропускает только:

- имена `*.userapi.com`, `*.vkuserphoto.ru`, `*.okcdn.ru` — серверы, где ВК хранит фото, голосовые, документы и обложки видео;
- адреса самого компьютера (`127.0.0.1`, `::1`, `localhost`) — на них работает страница-пульт;
- соединения с IP-адресом, который замок **сам** получил для разрешённого имени.

Всё остальное — исключение: имя не ищется в DNS, соединение не открывается. Попытка пишется в `logs/network.log` с пометкой `ЗАБЛОКИРОВАНО` и появляется на экране «Безопасность». Каждое новое разрешённое имя тоже пишется в журнал — по нему видно всё, с кем программа говорила.

Тест `tests/test_firewall.py` проверяет в отдельном процессе, что замок обрывает: поиск чужого имени, `urllib` на чужой сайт, соединение с голым IP (`1.1.1.1`), UDP-пакет на `8.8.8.8`, похожие имена (`userapi.com.evil.ru`) и **API ВК** (`api.vk.com`).

### Один сетевой модуль — `vkbackup/net.py`

Единственная функция, которая ходит в интернет, — `download(url, dest)`: только GET, только HTTPS с проверкой сертификата, только порт 443, соединение открывает замок. Перенаправление на чужой сервер тоже проходит через замок и обрывается.

### Тест-сторож — `tests/test_audit.py`

Он разбирает исходный код и падает, если:

- сетевые модули (`socket`, `ssl`, `http.client`, `urllib.request`, `requests`, `httpx`, `asyncio`…) импортируются где-то, кроме `firewall.py`, `net.py` и `webapp/ports.py` (последний только ищет свободный порт на `127.0.0.1`);
- в коде появляется выполнение строк (`eval`, `exec`, `compile`, `__import__`), запуск программ (`subprocess`, `os.system`, `os.popen`), `pickle`, `marshal` и т. п. Исключения перечислены поимённо с причиной: `ctypes` — чтобы Windows не уснула во время скачивания, `os.startfile` — открыть папку архива по кнопке;
- замок перестаёт быть первой строкой `webui.py`;
- у программы появляется третья зависимость;
- страница-пульт или стили архива начинают грузить что-либо из интернета.

Тест запускается на каждое изменение кода (GitHub Actions, Windows/macOS/Linux) — его результат виден в репозитории.

### Страница-пульт — только для этого компьютера

Сервер слушает только `127.0.0.1`: с другого компьютера в сети к нему не подключиться. Запросы с чужих сайтов (CSRF, DNS-rebinding) отсекаются проверкой заголовков `Host`, `Origin` и `Sec-Fetch-Site` — тест `tests/test_webui.py`. Страница не грузит ничего из интернета: это закреплено заголовком `Content-Security-Policy`.

Через пульт можно смотреть и готовый архив: адреса `/archive/…` отдают файлы из выбранной вами папки архива — и только из неё (кроме базы `vk_backup.db`). Чужой сайт не может ни прочитать эти страницы, ни даже проверить, есть ли они: запросы с другого сайта к `/archive/` отсекаются так же, как к `/api/` (тест `tests/test_insights.py`).

### Страницы готового архива — без скриптов и без интернета

В каждой странице архива — политика безопасности `Content-Security-Policy`: `script-src 'none'; connect-src 'none'`, картинки и стили — только из папки архива, встроенные стили запрещены. Графики на странице «Мой ВКонтакте в цифрах» нарисованы атрибутами SVG, без скриптов и без атрибута `style`. Даже если бы в тексте сообщения оказалась вредная ссылка на картинку, браузер её не загрузит. Ссылки на профили ВК — обычные ссылки: они ничего не делают, пока вы по ним не кликнете, и не передают, откуда переход (`rel="noreferrer"`).

### Зависимости — две, зафиксированные

`fastapi` и `uvicorn` — только для страницы-пульта, в сети они не работают. Точные версии и SHA-256 каждого пакета записаны в `uv.lock`: uv откажется ставить пакет, если его содержимое не совпало. Сам `uv.exe` лаунчер `webui.bat` скачивает с официального GitHub uv и сверяет SHA-256 до распаковки.

## 3. Проверьте сами

### За 5 минут, без навыков

**Отключите интернет.** Снимите на главной галочку «Скачать фото, голосовые и файлы…» (или выключите Wi-Fi) и нажмите «Сохранить». Переписки, друзья, стена, музыка сохранятся: программе для них сеть не нужна. (Нужна только при **первом** запуске — см. «Первый запуск» ниже.)

**Посмотрите, с кем говорит программа — глазами Windows.** Пока идёт скачивание фото:

1. Нажмите Win+R, введите `resmon`, Enter — откроется «Монитор ресурсов».
2. Вкладка «Сеть» → «Сетевая активность» → отметьте `python.exe`.
3. В «TCP-подключениях» — удалённые адреса. Скопируйте любой и проверьте на [2ip.ru/whois](https://2ip.ru/whois/) или аналоге: владелец — **VKontakte Ltd / VK LLC** (автономные системы AS47541, AS47764 и соседние).

Удобнее — бесплатный [TCPView](https://learn.microsoft.com/sysinternals/downloads/tcpview) от Microsoft: он показывает имена серверов, а не только адреса. Все они должны кончаться на `userapi.com`, `vkuserphoto.ru` или `okcdn.ru` — плюс `127.0.0.1` (страница-пульт).

**Сверьте с журналом программы:** `logs/network.log` — каждое имя, к которому программа обращалась, и каждая заблокированная попытка. Экран «Безопасность» показывает то же самое вживую.

### За 15 минут — проверка по трафику

[Wireshark](https://www.wireshark.org/) показывает, с какими именами устанавливается каждое HTTPS-соединение (поле SNI), — независимо от того, что о себе говорит программа.

1. Запустите Wireshark на основном сетевом адаптере.
2. В фильтр введите `tls.handshake.extensions_server_name` и нажмите Enter.
3. Запустите в программе «Сохранить» со скачиванием файлов.
4. Колонка Info / поле Server Name: только `*.userapi.com`, `*.vkuserphoto.ru`, `*.okcdn.ru`.

Для чистоты закройте браузер и другие программы на время проверки — иначе в списке будут их соединения.

### Для тех, кто читает код

- Весь сетевой код — `vkbackup/firewall.py` и `vkbackup/net.py`. Остальное с сетью не работает — проверьте поиском:

  ```bash
  grep -rnE "import (socket|ssl|http|urllib\.request|requests|httpx|asyncio)|from (socket|ssl|http|urllib\.request) " vkbackup webapp webui.py
  ```

- Запустите тесты-сторожа: `uv run pytest -q tests/test_audit.py tests/test_firewall.py`.
- Сверьте файлы с опубликованными: экран «Безопасность» → «Отпечатки файлов программы» показывает SHA-256 каждого файла с кодом. Посчитать самому: `certutil -hashfile vkbackup\net.py SHA256` (Windows) или `sha256sum vkbackup/net.py`.
- Попросите независимый ИИ (Claude, ChatGPT, DeepSeek) или знакомого программиста провести аудит. Пример запроса:

  > Вот исходный код программы на Python. Найди любые места, где данные пользователя могут уйти куда-либо, кроме скачивания файлов по ссылкам с серверов *.userapi.com, *.vkuserphoto.ru, *.okcdn.ru. Проверь сетевые вызовы, запись файлов, запуск процессов, выполнение строк как кода, зависимости и обход сетевого замка в vkbackup/firewall.py. Перечисли всё подозрительное с файлом и строкой.

### Первый запуск

При самом первом запуске `webui.bat` / `webui.sh` скачивают — **до** старта программы и не через неё:

- `uv` — с `github.com` (проверяется SHA-256, записанный в `webui.bat`);
- Python — с `github.com` (сборки python-build-standalone, uv проверяет их сам);
- FastAPI, Uvicorn и их зависимости — с `pypi.org` / `files.pythonhosted.org` (по SHA-256 из `uv.lock`).

В «Мониторе ресурсов» это соединения процесса `uv.exe`, а не `python.exe`. Дальше программа запускается без них — можно проверить, отключив интернет.

## Чего программа гарантировать не может — честно

- **Замок стоит внутри той же программы, которую проверяет.** Он защищает от ошибок и от чужого кода в зависимостях, но не от автора: в новой версии автор мог бы его убрать. Поэтому главная гарантия — открытый код, тест-сторож, который видно в репозитории, и проверка **снаружи** (Монитор ресурсов, TCPView, Wireshark). Обновляясь, сверяйте, что изменилось.
- **Аудит-хуки Python — не песочница.** Код, вызывающий системные функции напрямую через `ctypes`, мог бы их обойти. В программе `ctypes` используется в одном месте — чтобы Windows не уснула во время скачивания (`SetThreadExecutionState`), — и тест-сторож не даст добавить его в другое.
- **ВК видит, что вы скачиваете свои файлы.** Ссылки в архиве подписаны: сервер ВК может понять, что это файлы из вашего архива, — как и когда вы открываете их в браузере. Третьим лицам это не передаётся.
- **Готовый архив на диске не зашифрован.** В нём ваши переписки, а в исходном архиве ВК — ещё и телефон, почта, история входов. Храните папку и ZIP там, куда нет доступа чужим. При необходимости — BitLocker (Windows), FileVault (macOS) или VeraCrypt.
- **Браузер и система — вне программы.** Расширения браузера видят страницы, которые вы в нём открываете, — в том числе страницы архива. Открывайте архив в браузере без сомнительных расширений.
